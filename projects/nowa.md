# NOWA Finance

> **State**: devnet farm — written 1:1 TGE conversion
> **Last verified**: 2026-10-23

## What it is

A DeFi protocol running a devnet farming phase. Test funds are issued on a devnet, used for test transactions, and earn NOWA Coins.

## Token status

No token launched. The project states in writing that **NOWA Coins convert 1:1 into a TGE allocation** — a rare case of a published conversion rule at the devnet stage.

## Rules as written

1. Claim devnet test funds from the faucet
2. Perform test transactions
3. Accrue NOWA Coins
4. Coins convert 1:1 at TGE

Cost: zero. The funds are test assets with no market value.

## Domain warning

There is a separate page at the root domain `nowa.finance` running a promotion that asks users to **pay 0.00065 BNB to receive 20,000 NOW tokens**. The team and funding behind that page are not transparent, and third-party security tooling flags the domain.

**A promotion that requires a payment to receive tokens is not an airdrop.** Use the `app.` subdomain listed in the official documentation, entered by hand.

## Risk notes

- The 1:1 conversion is written down, which is strong for this stage — but the total coin supply is unknown, so the 1:1 rate does not imply a value.
- Leaderboard rankings are competitive and based on USDT-denominated volume. Do not treat leaderboard position as an objective; the farming itself is the free part.
- Devnet phases can be reset. Activity on a devnet is not the same as activity on a network whose state is permanent.
