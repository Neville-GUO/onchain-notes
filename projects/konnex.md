# Konnex

> **State**: points only — weekly cadence
> **Last verified**: 2026-10-23

## What it is

A DePIN network. Participation is structured around weekly testnet onboarding rather than daily micro-tasks, which makes it one of the lower-maintenance items in a portfolio.

## Token status

No token announced. Points are tracked through a task panel. Treat as *points only*.

## Rules as written

- **Connect X first.** The task panel does not unlock its full set of tasks until a social account is linked.
- Weekly testnet onboarding: **500 points**
- Check-in: **10 points**
- Daily referral return: 10%
- VIP badge tiers apply a multiplier to allocation — the highest tier adds up to +75%
- Autonomous Units contribute an additional multiplier

## Deadlines

| Cadence | Action |
|---|---|
| Weekly | Testnet onboarding task resets |
| Daily | Check-in |

## Notes

The weekly structure is the appeal: 500 points for one task per week is a better rate of return on attention than the daily-quest model most of these programmes use. The catch is that a missed week is a missed reset, not a deferral.

The VIP tier system is where the actual allocation differentiation happens. Earning a badge is worth more than repeating the base tasks, if the badge is attainable without capital.

## Risk notes

- The multiplier structure means a passive participant and an active one can receive very different allocations from identical task completion. Read the badge requirements before assuming the base rate applies.
- DePIN projects frequently attach hardware requirements at higher tiers. Verify before planning around them.
