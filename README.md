# Onchain Notes

Personal research notes on early-stage onchain networks — the rules as written, the deadlines that matter, and the mistakes worth remembering.

Not investment advice. Nothing here is a recommendation to buy, sell, or hold anything.

## Why this exists

Most information about early-stage networks is repeated second-hand and drifts from the source. I keep this repo to hold myself to a simple rule: **write down what the project actually says, not what a summary blog says it says.**

## How notes are kept

- **Only official sources.** Docs, blog posts, terms, and announcements from the project itself. Aggregators are pointers, not proof.
- **Every entry carries a verification date.** Rules change; a note without a date is a liability.
- **Three states, never blurred:**
  - *Token confirmed* — the project has published an allocation or conversion rule in writing
  - *Points only* — a points system exists, but no token has been promised
  - *Denied* — the project has explicitly said there is no token
- **Deadlines get a date and a timezone.** "Coming soon" is not a deadline.
